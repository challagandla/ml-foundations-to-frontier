Part 1 · Build the mental model

What is programming?

Programming is writing precise instructions that a computer can follow. Those instructions are called code or source code. A complete collection of instructions that performs a task is a program.

Computers are fast, but extremely literal. They do not guess what you meant. A programming language gives humans a consistent vocabulary and grammar for expressing instructions. Python is one such language. It is popular in machine learning because its code is readable and it has excellent data and ML libraries.

1 · You write source code

Human-readable text such as print("Hello").

2 · Python interprets it

The interpreter reads the code and determines what each instruction means.

3 · The computer acts

It calculates, stores data, displays output, or repeats instructions.

The Python interpreter is the program that executes Python code. In a Jupyter notebook, you write code inside a rectangular code cell. Running the cell sends its code to the interpreter. The result appears below the cell.

Three words beginners often mix up

Code is the written instruction. Python is the language and its rules. The interpreter is the software that reads Python code and carries out the instruction.

Python's grammar: syntax

Every language has rules about how words and symbols may be arranged. In programming, those rules are called syntax. For example, Python requires matching quotation marks and parentheses. Correct syntax: print("Hello"). Incorrect syntax: print("Hello). Code that breaks the grammar produces a SyntaxError.

Python is case-sensitive: uppercase and lowercase letters are treated as different. print, Print, and PRINT are three different names. Only the lowercase built-in print exists by default.

Your first line of Python

print("Hello, Python!")
Hello, Python!

This one line introduces several important terms:

print("Hello, Python!")

print is the name of a function—a reusable action. This function displays information.

( ) mean “call” or “run” the function. A function call asks Python to perform the function's action now.

"Hello, Python!" is the argument—the information given to the function.

The quoted text is a string, Python's type for text.

A statement is an instruction that Python can execute. The function call above is a statement. Python normally executes statements from top to bottom:

print("First")
print("Second")
print("Third")
First Second Third

Comments: notes for humans

A comment explains code to human readers. An unquoted # begins a comment, and Python ignores the rest of that line. A # inside quoted text is simply a character in the string.

# This whole line is a comment.
print("Welcome!")  # This comment follows an instruction.

Good comments explain why something is done or clarify a surprising choice. They should not narrate an obvious line. Code is read far more often than it is written, so use clear names first and comments where they add context.

Part 2 · Represent and store information

Values and data types

A value is one piece of information that a program can work with: the number 42, the text "Dubai", or the truth value True. A value written directly in code is called a literal.

Every value has a data type, usually shortened to type. The type tells Python what the value represents and which operations make sense. Adding two numbers makes sense; subtracting one person's name from another does not.

int · integer

A whole number with no decimal point. It may be positive, negative, or zero.

42 -7 0
float · floating-point number

A number with a decimal point, or one written in scientific notation.

3.14 -0.5 2.0 1e-3
str · string

Text enclosed in matching single or double quotation marks.

"hello" 'ML' "42"
bool · Boolean

A truth value. There are exactly two: capitalized True and False.

True False
NoneType · absence marker

None is itself a special value used to mean “missing” or “not set.”

None

Scientific notation is a compact way to write very large or small numbers: 1e-3 means 1 × 10−3, which is 0.001. The e stands for “times ten to the power of.”

Text that looks like a number is still text

42 is an integer, but "42" is a two-character string. Quotation marks change the type. Python can calculate 42 + 8, but "42" + "8" joins text and produces "428".

Ask Python for a type with type()

type() is a built-in function. Built-in means Python provides it automatically; you do not need to install or define it.

print(type(42))
print(type(3.14))
print(type("42"))
print(type(True))
print(type(None))
<class 'int'> <class 'float'> <class 'str'> <class 'bool'> <class 'NoneType'>

You can read <class 'int'> as “this value belongs to the integer type.” The word class will be explained properly in Module 03; for now, “type” is enough.

Converting between types

Type conversion creates a value of one type from a value of another. Python's conversion functions use the type names:

CodeResultExplanation
int("42")42Convert numeric text to an integer.
float("3.5")3.5Convert numeric text to a float.
float(7)7.0Convert an integer to a float.
int(3.9)3Remove the decimal part; this does not round.
str(42)"42"Convert a value to displayable text.
bool(0)FalseZero is considered false in a Boolean context.

A conversion can fail if the original value has the wrong form. int("forty-two") raises a ValueError because those letters cannot be interpreted as an integer.

Optional deep dive Why 0.1 + 0.2 is surprising

Integers are exact in Python, but most decimal fractions cannot be stored exactly as binary floating-point numbers. Python stores the closest available approximation. That is why 0.1 + 0.2 displays as 0.30000000000000004.

This is normal across mainstream languages, not a Python bug. For approximate float comparison, import Python's math toolkit and use math.isclose(a, b) rather than a == b:

import math
print(math.isclose(0.1 + 0.2, 0.3))  # True

This matters later when ML models perform millions of decimal calculations. Imports are taught properly in Module 03; the example simply shows the safe tool.

Variables and assignment

A variable is a name that refers to a value. An assignment statement creates or updates that relationship:

age = 25
city = "Dubai"
is_student = True

The single equals sign = is the assignment operator. Read age = 25 as “age gets 25” or “assign 25 to age.” It does not mean mathematical equality.

Evaluate the right side→produce a value→attach the left-side name

This right-side-first rule makes the following code sensible:

score = 10
score = score + 5
print(score)
15

On the second line, Python first looks up the current value of score, calculates 10 + 5, then makes score refer to the new value 15. The old value is not edited; the name is reassigned.

Names, identifiers, and keywords

A name used in code is formally called an identifier. Python identifiers:

  • may contain letters, digits, and underscores: model_2
  • cannot begin with a digit: 2_model is invalid
  • cannot contain spaces or hyphens: use learning_rate, not learning rate
  • are case-sensitive: score and Score are different names
  • cannot be Python keywords such as if, for, or True

Python style uses snake_case: lowercase words separated by underscores. Prefer descriptive names that explain meaning and unit.

Hard to understand

x = 120
y = 0.25
z = x * (1 - y)

Clear and specific

price_aed = 120
discount_rate = 0.25
sale_price_aed = price_aed * (1 - discount_rate)

Python is dynamically typed

You do not declare a variable's type before using it. The name can later refer to a different type:

result = 95       # result currently refers to an int
result = "pass"   # now it refers to a str

This flexibility is called dynamic typing. It is convenient, but changing a name's meaning or type without a good reason makes code harder to understand. Prefer one consistent meaning per variable.

Output, strings, and input


  
print() in detail

  
Output is information a program sends outward—for example, text displayed
  below a notebook cell. print() can receive zero, one, or several arguments.
  Multiple arguments are separated by commas:


  
name = "Maya"
score = 92

print("Learner:", name)
print("Score:", score, "points")
print()

  
Learner: Maya
Score: 92 points



  
By default, print() places a space between arguments and a newline after
  them. A newline moves the next output to a new line. Two optional
  keyword arguments change those defaults:


  
print("red", "green", "blue", sep=" | ")
print("Loading", end="...")
print("done")

  
red | green | blue
Loading...done


  
sep means separator; end means what to place after the final
  argument. The name=value syntax passes an option by name. You will learn
  how to define your own functions with parameters in Module 02.


  
String basics

  
Strings may use either matching single or double quotes. Choose the outer quotes so
  text inside remains readable:


  
message = "Python is readable."
apostrophe = "It's a string."
quotation = 'She said "hello".'


  
An escape sequence begins with a backslash and represents a special
  character. Common examples are \n for a newline, \t for a tab,
  \" for a double quote, and \\ for a backslash.


  
print("First line\nSecond line")
print("Name\tScore")
print("Maya\t92")

  
First line
Second line
Name    Score
Maya    92


  
f-strings: insert values into text

  
An f-string is a string prefixed with f. Expressions inside
  curly braces { } are evaluated and inserted into the text.


  
name = "Maya"
score = 92
maximum = 100

print(f"{name} scored {score} out of {maximum}.")
print(f"Percentage: {score / maximum * 100:.1f}%")

  
Maya scored 92 out of 100.
Percentage: 92.0%


  
In :.1f, f means fixed-point decimal format and
  .1 requests one digit after the decimal point. Formatting changes how the
  value is displayed, not the value stored in the variable.


  
input(): receive text from a user

  
Input is information a program receives. The built-in
  input() function displays a prompt, pauses, and returns whatever the user
  types. Crucially, input() always returns a string.


  
name = input("What is your name? ")
age_text = input("How old are you? ")
age = int(age_text)

print(f"Hello, {name}. Next year you will be {age + 1}.")


  
If the user types 25, age_text holds the string
  "25". int(age_text) converts it before arithmetic. Later,
  Module 03 will teach how to handle invalid input safely.

Basic string methods

  
A method is a function associated with a particular type of value. Call
  one with dot notation: value.method(). Common string methods return a new

raw_name = "  Maya Ahmed  "

  immutable: these methods create new strings; they do not edit the original.
  Store the returned value if you need it later.

Precedence: which operation happens first?

  
Operator precedence is the order Python uses when an expression has several
  operators. The useful beginner order is:

  
    
    
  1. Parentheses ( )
    2. 
    
  2. Exponentiation **
    3. 
    
  3. Unary signs +x, -x
    4. 
    
  4. Multiplication and division *, /, //, %
    5. 
    
  5. Addition and subtraction +, -
    6. 
    
  6. Comparisons, then not, then and, then or
    7.

Do not make readers memorize a complicated expression. Use parentheses to make intent

Truthiness

  
Python can treat non-Boolean values as true or false in a condition. This is called
  truthiness. The values False, None, numeric zero,
  and empty strings are falsy. Most other values are truthy.


  
print(bool(0))       # False
print(bool(""))      # False
print(bool(None))    # False
print(bool(12))      # True
print(bool("no"))    # True: it is non-empty text


  
Important: bool("False") is True because the string contains
  characters. Python does not interpret the word inside the string.


  
Membership and chained comparisons

  
The membership operators in and not in ask
  whether a value occurs inside another value. For now, use them with text; Module 02 uses
  the same operators with lists, dictionaries, and sets.


  
message = "machine learning"

print("learn" in message)         # True
print("Python" not in message)    # True


  
Python also allows a readable chained comparison. The two conditions below mean the
  same thing:


  
age = 25
print(age >= 18 and age < 65)
print(18 <= age < 65)


  
To ask whether a value is specifically the missing-value marker None,
  Python style uses value is None or value is not None.
  The is operator asks about object identity; Module 02 explains that
  distinction in depth.

Decisions with if, elif, and else


  
A conditional statement runs different code depending on a condition.
  This creates branches—alternative paths through a program.


  
temperature = 35

if temperature >= 30:
    print("It is hot.")


  
The structure has four pieces:

  
    
    
  1. The keyword if begins the conditional.
    2. 
    
  2. The condition is an expression evaluated as true or false.
    3. 
    
  3. The colon : says an indented block follows.
    4. 
    
  4. The indented code block belongs to the if and runs only if the condition is true.
    5. 
  


  
Indentation is part of Python's syntax

  
Indentation means spaces at the beginning of a line. Python convention is
  four spaces per level. All lines in the same block must be aligned:


  

    

      
Correct

      
if score >= 50:
    print("Pass")
    print("Well done")
print("Finished")

    

    

      
Incorrect

      
if score >= 50:
print("Pass")  # not indented

    

  


  
In the correct version, both indented lines belong to the branch. The final unindented
  line is outside the branch and always runs.


  
Two paths with else

  
score = 47

    result = "pass"
else:
    result = "try again"

print(result)


  
else has no condition. It runs only when the preceding
  if condition is false. Exactly one of these two blocks runs.


  
Several paths with elif

  
elif is short for “else if.” Python checks conditions from top to bottom,
  runs the first true branch, and skips the rest of the chain.

  Part 5 · Repeat work
  
Repetition with loops


  
A loop repeats a code block. One pass through the block is an
  iteration. Python has two main loop forms:

  
    
    
  • while: repeat while a condition remains true.
    • 
    
  • for: repeat once for each value in an iterable—something
    that can provide values one at a time. Here we begin with range().
    • 
  


  

    
Which loop should I choose?

    
Use for when you have known values to visit or a known number of
    repetitions. Use while when repetition ends because a changing condition
    becomes false—especially when you do not know the number of iterations in advance.
    If either form works, choose the one that makes the stopping rule easiest to see.

  


  
while: condition-controlled repetition

  
count = 3

while count > 0:
    print(count)
    count -= 1

print("Go!")

  
3
2
1
Go!


  
Trace it carefully:

  
    
    
  1. Set count to 3.
    2. 
    
  2. Check count > 0. It is true, so run the block.
    3. 
    
  3. Print 3 and decrease count to 2.
    4. 
    
  4. Return to the condition and repeat for 2, then 1.
    5. 
    
  5. After count becomes 0, the condition is false. Exit the loop.
    6. 
    
  6. Run the next unindented statement and print Go!.
    7. 
  


  
A three-step countdown is a known sequence, so a for loop is arguably
  clearer. Both versions are valid:


  

    

      
Known count: prefer for

      
for count in range(3, 0, -1):
    print(count)
print("Go!")

    

    

      
Changing condition: while

      
count = 3
while count > 0:
    print(count)
    count -= 1
print("Go!")

    

  


  

    
Every while loop needs a path to stop

    
If the condition never becomes false, the program has an infinite loop.
    In a notebook, use the interrupt/stop button if this happens. Before running a
    while loop, identify which value changes and why that change will
    eventually make the condition false.

  


  
for and range(): count-controlled repetition

  
for number in range(1, 4):
    print(number)

  
1
2
3


  
number is the loop variable. On each iteration it receives
  the next value. range() describes a sequence of integers:


  

    
FormMeaningValues

    
      
range(stop)Start at 0; step by 1range(5) → 0, 1, 2, 3, 4

      
range(start, stop)Choose the start; step by 1range(2, 6) → 2, 3, 4, 5

      
range(start, stop, step)Choose all threerange(2, 9, 2) → 2, 4, 6, 8

      
range(5, 0, -1)Negative step counts down5, 4, 3, 2, 1

    
  


  
The start is included; the stop is excluded. This half-open interval rule
  appears throughout Python. Think “start here, stop before there.”


  
A for loop can also visit the characters of a string directly:


  
for letter in "ML":
    print(letter)

  
M
L


  
The string is the iterable, and letter receives one character per
  iteration. Module 02 generalizes this pattern to lists, dictionaries, and other
  containers.

Accumulators and counters

  
An accumulator is a variable that collects a result across iterations.
  A counter is a variable used to count events. Initialize before the loop,
  update inside it, and use the final value afterward:


  
total = 0

for number in range(1, 6):
    total += number

print(total)  # 15


  
The initial value matters. A sum normally starts at 0; a product normally
  starts at 1.


  
break and continue

  
break exits the nearest loop immediately. continue skips the
  rest of the current iteration and starts the next one.


  
for number in range(1, 8):
    if number == 3:
        continue        # skip 3
    if number == 6:
        break           # stop before printing 6
    print(number)

  
1
2
4
5


  
These tools are useful, but a loop with many break and
  continue statements can be difficult to trace. Prefer the clearest control
  flow.


  
Nested control flow

  
A block may contain another conditional or loop. This is called nesting.
  Each level adds four more spaces:


  
for number in range(1, 6):
    if number % 2 == 0:
        print(f"{number} is even")
    else:
        print(f"{number} is odd")

  Part 6 · Learn from mistakes
  
Errors and debugging


  
An error means Python could not complete an instruction as written.
  Errors are normal feedback, not evidence that you are bad at programming.
  Debugging is the process of finding and correcting the cause.


  
When Python stops with an error, it prints a traceback. Read it from the
  bottom upward: the last line gives the error type and message; the lines above show where
  it happened.


  
print(points)

  
Traceback (most recent call last):
  File "lesson.py", line 3, in <module>
    print(points)
          ^^^^^^
NameError: name 'points' is not defined


  
Translate the message into plain language: “Python reached the name
  points, but no value has been assigned to that name.” Then check spelling,
  capitalization, and whether the assignment cell ran.


  
    
    
  1. File "lesson.py", line 3 identifies the location.
    2. 
    
  2. print(points) shows the statement that failed; carets point at the
    relevant part when Python can identify it.
    3. 
    
  3. The final line gives the error type (NameError) and its message.
    Start here, then work upward to the location.
    4. 
  


  

    

      SyntaxError
      
Python cannot parse the code's grammar. Check quotes, parentheses, colons, and accidental punctuation.

    

    

      IndentationError
      
Indentation is missing or inconsistent. Align every line in the same block, normally with four spaces.

    

    

      NameError
      
A name has not been defined. Check spelling, capitalization, and cell execution order.

    

    

      TypeError
      
An operation received an unsuitable type—for example, adding a string and integer.

    

    

      ValueError
      
The type is acceptable but the value has the wrong form—for example, int("hello").

    

    

      ZeroDivisionError
      
A calculation tried to divide by zero. Check the denominator before division.

    

  


  
Syntax errors, runtime errors, and logic errors

  
    
    
  • A syntax error prevents Python from understanding the code.
    • 
    
  • A runtime error occurs while valid-looking code executes, such as division by zero.
    • 
    
  • A logic error does not necessarily produce a message; the program runs but gives the wrong answer.
    • 
  


  
# Logic error: this calculates a 20% increase, not a 20% discount.
price = 100
discounted_price = price * 1.20


  
A reliable debugging routine

  
    
    
  1. Read the entire final error line.
    Identify the error type and translate the message into plain language.
    2. 
    
  2. Find the referenced line.
    The bug may be on that line or in a value created shortly before it.
    3. 
    
  3. Inspect names, values, and types.
    Use temporary calls such as print(value, type(value)).
    4. 
    
  4. Reduce the problem.
    Run a smaller piece of the expression or fewer loop iterations.
    5. 
    
  5. Change one thing and re-run.
    Confirm that the change explains the result; do not make several guesses at once.
    6.
