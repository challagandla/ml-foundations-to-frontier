00 · Orientation & How This Course Works

Two minutes here saves confusion in all 41 modules after it — here's exactly what you'll see on every module page, and what to do with it.

Learning objectives

  • Navigate any future module confidently
  • Know the difference between the HTML page and the notebook, and when to use each
  • Understand how the optional "Math Deep Dive" sections work

Two files per module

Every module lives in its own folder, modules/NN-slug/, and always contains exactly two files:

index.html is the lesson itself: intuition, diagrams, an interactive demo you manipulate with your mouse, worked examples, and a short quiz. Open it in any browser — nothing to install.

notebook.ipynb is where the same ideas become runnable code — a small version of the page's demo, guided exercises, and a from-scratch implementation you compare against a library like scikit-learn. This is where you actually build understanding by doing; don't skip it.

Try the two interactive pieces you'll see everywhere

Every module page uses two recurring widgets. Try them right here so they're familiar later.

Math deep dive This is what a deep dive looks like

Deep dives hold the full derivation or proof behind a concept — calculus, linear algebra, whatever the topic needs. They're collapsed by default because you don't need them to follow the lesson. Expand one when you want the rigor; skip it when you just want the intuition and the formula. Nothing later in a module depends on you having opened one.

Reading the phase badges

The colored pill at the top of each page (like Foundations above) tells you which of the four phases a module belongs to: Foundations, Classical ML, Deep Learning, or the Applied/LLM track. The dashboard groups modules by phase using the same colors.

Key takeaways

  • Each module = one index.html (read/interact) + one notebook.ipynb (run/edit)
