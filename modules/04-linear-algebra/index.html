04 · Linear Algebra Essentials

A linear regression model, a neural network layer, and an attention head are all, underneath, vectors and matrices moving through space. If you can picture what a matrix does to a grid of points, most of the rest of this course is a variation on that one picture.

Learning objectives

  • Read and write vector/matrix notation
  • Compute dot products and norms by hand
  • Picture a matrix as a transformation of space

A vector is an arrow

A vector like v = (3, 1) is just a list of numbers — but geometrically, it's an arrow from the origin to the point (3, 1). The two numbers are how far to go along each axis. Every operation in this module has both a "list of numbers" reading and an "arrow" reading — use whichever makes a given step click.

Demo 1 — vector addition

Adding two vectors, u + v, means: walk along u, then walk along v from wherever you land. The result is the same no matter which one you walk first — that's the parallelogram you'll see form below. Drag the sliders and watch the sum vector respond.

■ u   ■ v   ■ u + v = (4, 3) — notice it's always the fourth corner of the dashed parallelogram.

Key formulas

u + v = (u₁ + v₁, u₂ + v₂) — add component-wise.
c · v = (c·v₁, c·v₂) — scaling a vector by a number c stretches (|c| > 1), shrinks (|c| < 1), or flips (c < 0) the arrow, without changing its direction line.

Dot product: how aligned are two vectors?

The dot product u · v turns two vectors into a single number that measures alignment: large and positive when they point the same way, zero when they're perpendicular, negative when they point opposite ways. This one number is the computational core of linear regression, cosine similarity, and attention scores alike — it's worth building real intuition for it.

v = (3, 0) is fixed. u · v = 6.9 — the dashed segment is u's projection onto v: how much of u points "along v".

Math deep dive Dot product, norms, and the Cauchy–Schwarz inequality

Algebraic definition: for u = (u₁, u₂) and v = (v₁, v₂),

u · v = u₁v₁ + u₂v₂

Geometric definition:

u · v = |u| |v| cos(θ)

where θ is the angle between the vectors and |u| = √(u₁² + u₂²) is the norm (length) of u. These two definitions are equivalent — the demo above computes both and they agree.

Because cos(θ) is always between -1 and 1, this gives the Cauchy–Schwarz inequality: |u · v| ≤ |u| |v|, with equality exactly when u and v point along the same line. This is why cosine similarity, cos(θ) = (u · v) / (|u| |v|), is always safely between -1 and 1 — it's the dot product with the lengths divided back out, leaving pure "alignment."

The projection of u onto v — the length of the shadow u casts on the line through v — is |u| cos(θ) = (u · v) / |v|. That's the dashed segment in the demo.

A matrix is a transformation

A 2×2 matrix takes every point in the plane and moves it somewhere else, in a way that keeps grid lines straight, parallel, and evenly spaced (a linear transformation). The clearest way to see what a matrix does is to watch what it does to the unit square — the square with corners at (0,0), (1,0), (1,1), (0,1).

Dashed = the original unit square. Filled = the square after applying [[a, b], [c, d]]. Determinant (area scale factor) = 1.55.

Key formula

Matrix times vector, row by row:

[a  b]   [x]   [a·x + b·y]
[c  d] · [y] = [c·x + d·y]

Each output coordinate is a dot product of a matrix row with the input vector.

Math deep dive Why matrix multiplication isn't commutative, and what the determinant means

Matrices as functions. Applying matrix A then matrix B to a vector x is B(Ax), which equals (BA)x — matrix multiplication is defined precisely so that "apply A, then B" corresponds to the single matrix BA. Function composition isn't generally order-independent (put your socks on then shoes ≠ shoes then socks), and neither is this: in general AB ≠ BA. Try it with the sliders above by comparing the transform for (a,b,c,d) against (a,c,b,d) (its transpose) — different matrices, different results, generally.

The determinant, det = ad − bc for a 2×2 matrix, is the factor by which the matrix scales area. The unit square has area 1, so the transformed parallelogram's area is exactly |det|. If det is negative, the transformation also flips orientation (like a mirror) — watch the square "turn inside out" as you slide a or d negative enough above. If det = 0, the matrix squashes the whole plane onto a line (it destroys information — this is exactly what makes a matrix non-invertible).

Worked example

Let A = [[2, 0], [1, 3]] and x = (2, 1). Compute Ax:

row 1: 2·2 + 0·1 = 4
row 2: 1·2 + 3·1 = 5

Ax = (4, 5)

Set the sliders above to a=2, b=0, c=1, d=3 and you'll see the unit square stretched to 2× wide and sheared — consistent with a determinant of 2·3 − 0·1 = 6: six times the original area.

Common pitfall

Matrix multiplication is not commutative (AB ≠ BA in general) and the dot product is not the same as multiplying two vectors element-wise ((u₁v₁, u₂v₂), sometimes called the Hadamard product) — the dot product collapses to a single number; element-wise multiplication doesn't. Both mix-ups are common and both produce numbers that look plausible, so they're easy to miss — check dimensions and re-derive by hand when a result looks off.

Key takeaways

  • A vector is both a list of numbers and an arrow — add component-wise, or tip-to-tail
  • Dot product u · v = |u||v|cos(θ) measures alignment; it's 0 exactly when perpendicular
  • A matrix is a function on space — matrix-vector multiplication is dot products of rows with the input
  • The determinant is the area scale factor; zero means the matrix collapses the plane
